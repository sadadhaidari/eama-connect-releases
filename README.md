# EAMA Connect

[Download the Windows installer](https://github.com/sadadhaidari/eama-connect-releases/releases/latest)

Connect to the Jetson with a password or SSH key. Use Terminal for commands and Desktop for its VNC screen. Both use the same SSH connection over USB or Tailscale.

The Desktop tab needs the VNC server on the Jetson at 127.0.0.1:5901. Enter its desktop password when prompted.

Install once. The app checks for updates and offers Download and Restart buttons.

Windows installers are unsigned. A Mac installer is not published yet.
